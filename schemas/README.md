# Схемы

JSON Schema — общий контракт между сенсором (Go) и control plane (Python).

Зачем отдельный каталог: сенсор и control plane написаны на разных языках,
и единственный способ не дать контракту разойтись — описать его один раз
и проверять с обеих сторон тестами ([ADR-0002](../docs/adr/0002-controlplane-python.md)).

Наполнится на этапе 3, когда у контрактов появится второй читатель —
control plane. До этого источник истины для событий — формат v0
([ADR-0023](../docs/adr/0023-sensor-events.md)), для политики — формат v1
и его проверка в сенсоре ([ADR-0025](../docs/adr/0025-policy-format.md)).
Файл схемы, который никто не проверяет, неизбежно разошёлся бы с кодом.
