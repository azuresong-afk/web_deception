# ADR-0002. Control plane на Python (FastAPI)

Статус: принято. Дата: 2026-09-21.

## Контекст
Control plane содержит корреляцию, классификацию, реакцию и алерты — логику,
которую владелец проекта (инженер ИБ) должен понимать и проверять.
Производительность здесь менее критична, чем в сенсоре.

## Решение
Python и FastAPI. Контракт событий между сенсором и control plane описывается
в schemas/ (JSON Schema) и проверяется тестами с обеих сторон.

## Альтернативы
- Всё на Go — один язык и инструментарий, но владелец частично читает Python
  и не знает Go; аналитика и LLM-функции на Python развиваются быстрее.

## Последствия
Два языка в проекте и два набора инструментов в CI. Риск рассинхронизации
контракта снимается общими схемами и тестами.
