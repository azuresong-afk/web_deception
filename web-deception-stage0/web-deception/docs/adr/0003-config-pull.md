# ADR-0003. Сенсор забирает конфигурацию сам (pull)

Статус: принято. Дата: 2026-09-21.

## Контекст
Сенсор работает в сети клиента. Входящие соединения к нему усложняют
развёртывание и расширяют поверхность атаки.

## Решение
Сенсор инициирует только исходящие соединения и периодически забирает
конфигурацию по mTLS. Конфигурация подписана ключом, хранящимся отдельно
от сервера раздачи. При неверной подписи сенсор продолжает работать
на последней валидной конфигурации и отправляет событие.

## Альтернативы
- Push от control plane — мгновенное применение, но входящие порты у клиента
  и прямое управление сенсором при компрометации control plane.

## Последствия
Задержка применения конфигурации (интервал опроса). Взлом сервера раздачи
не позволяет раздать вредоносную конфигурацию (угроза T6).
