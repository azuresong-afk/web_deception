# ADR-0004. Очередь событий — NATS JetStream

Статус: принято. Дата: 2026-09-21.

## Контекст
События от сенсоров нужно надёжно доставлять в control plane, не замедляя трафик.

## Решение
NATS JetStream. Сенсор пишет события в локальный буфер фиксированного размера
и отправляет асинхронно; при переполнении старые события отбрасываются
со счётчиком потерь.

## Альтернативы
- Redis Streams — знаком многим, но часто работает без персистентности.
- Kafka — стандарт индустрии, но тяжёл для self-hosted у малого бизнеса.

## Последствия
Лёгкий компонент с хранением сообщений. Возможна потеря событий при перегрузке —
принятый риск R2.
