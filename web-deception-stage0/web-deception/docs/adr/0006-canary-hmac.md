# ADR-0006. Canary-токены с HMAC-подписью

Статус: принято. Дата: 2026-09-21.

## Контекст
Сенсор должен мгновенно распознавать свои canary-токены без обращения к базе.

## Решение
Токен = префикс + идентификатор выдачи + HMAC-подпись. Сенсор проверяет подпись
локально. Ключи ротируются, поддерживается несколько активных ключей на период ротации.

## Альтернативы
- Случайные токены с поиском в базе — зависимость критического пути от БД.

## Последствия
Мгновенная проверка, защита от подделки токенов (угроза T7).
Требуется безопасное хранение и ротация HMAC-ключей.
