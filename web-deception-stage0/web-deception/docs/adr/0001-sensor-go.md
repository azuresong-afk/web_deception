# ADR-0001. Сенсор на Go

Статус: принято. Дата: 2026-09-21.

## Контекст
Сенсор стоит в критическом пути трафика клиента. Нужны низкая задержка,
безопасность памяти, простое развёртывание и понятный для ревью код.

## Решение
Сенсор пишется на Go на базе стандартного net/http/httputil.ReverseProxy
и распространяется одним статически собранным бинарником.

## Альтернативы
- Rust — выше производительность и строже гарантии, но долгое освоение.
- Модуль Nginx на Lua (OpenResty) — быстрая интеграция, но сложно тестировать,
  привязка к Nginx.
- Фильтр Envoy на Wasm — мощно, но сложная отладка и эксплуатация.

## Последствия
Безопасность памяти и простой деплой. На Go написаны Caddy и Traefik — подход
проверен в продакшене. Владельцу нужно научиться читать Go на базовом уровне.
Интеграции с Nginx и Envoy можно добавить позже как дополнительные режимы.
