# Control plane

Python + FastAPI. Корреляция событий в профили атакующих, классификация
«шум / целевая атака», решения о реакции, алерты, API для дашборда.

Не находится в критическом пути трафика: если control plane недоступен,
сенсор продолжает работать на последней валидной конфигурации.

Решение: [ADR-0002](../docs/adr/0002-controlplane-python.md).

Появится на шаге 3 этапа 1 (минимальный сервис), наполнится на этапах 3–4.
