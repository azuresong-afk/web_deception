# Интеграционные и e2e тесты

Unit-тесты лежат рядом с кодом (`sensor/`, `controlplane/`). Здесь — тесты,
которым нужен поднятый стек целиком.

Ключевой сценарий: OWASP Juice Shop за нашим сенсором. Проверяем, что
приложение работает нормально, приманки срабатывают, а fail-open включается
при остановке зависимостей сенсора.

Появится на шаге 5 этапа 1 (каркас), наполнится с этапа 2.
