# Собственные правила Semgrep

Здесь живут правила, которые автоматически проверяют раздел «Запрещено»
из [CLAUDE.md](../../CLAUDE.md):

- запрет логирования тел запросов и ответов, заголовков `Authorization`,
  `Cookie`, `Set-Cookie`, токенов и паролей (угроза T4);
- запрет доверия `X-Forwarded-For` вне списка доверенных прокси (угроза T1);
- запрет образов с тегом `latest` и GitHub Actions по тегу вместо SHA (угроза T12).

Смысл: правило, за соблюдением которого следит только человек, рано или поздно
нарушается. Правило, за которым следит CI, — нет.

Появится на шаге 6 этапа 1.
