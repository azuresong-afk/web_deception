# ADR-0008. Монорепозиторий

Статус: принято. Дата: 2026-09-21.

## Контекст
Команда 1–3 человека, сенсор и control plane связаны общим контрактом.

## Решение
Все компоненты в одном репозитории с общим CI.

## Альтернативы
- Отдельные репозитории — независимые релизы, но сложная синхронизация контракта.

## Последствия
Атомарные изменения контракта в одном PR, единые проверки. CI должен запускать
только затронутые части, чтобы оставаться быстрым.
