# ADR-0007. Минимизация данных

Статус: принято. Дата: 2026-09-21.

## Контекст
Через сенсор проходят пароли и персональные данные. IP-адрес — персональные
данные по GDPR и 152-ФЗ.

## Решение
Сенсор отправляет только метаданные: метод, путь, статус, размеры, тайминги,
отпечатки, хеш идентификатора сессии. Тела и заголовки авторизации не покидают
сенсор. Срок хранения событий по умолчанию 90 дней, настраивается.

## Альтернативы
- Полная запись трафика — богаче для расследований, но огромный риск утечки
  и юридические ограничения.

## Последствия
Меньше данных для глубокого расследования. Продукт юридически применим
в ЕС и РФ, а его компрометация не раскрывает трафик клиентов.
