# ADR-0005. Хранилище — PostgreSQL

Статус: принято. Дата: 2026-09-21.

## Контекст
Нужно хранить конфигурацию, профили атакующих, аудит и события.

## Решение
PostgreSQL. События — в таблицах с партиционированием по времени.

## Альтернативы
- ClickHouse — лучше для аналитики больших объёмов, но лишняя сложность для MVP.
- TimescaleDB — удобные временные ряды, но дополнительное расширение и лицензия.

## Последствия
Одна СУБД на всё в MVP. Переход событий в ClickHouse возможен без изменения
сенсора, так как события приходят через очередь.
