# ADR-0010. Структура монорепозитория

Статус: принято. Дата: 2026-09-22.

## Контекст
[ADR-0008](0008-monorepo.md) зафиксировал монорепозиторий, но не описал, как
разложить внутри него два языка. Нужна раскладка, которая решает три задачи:
CI должен проверять только изменившуюся часть, владелец-неразработчик должен
понимать, где что лежит, а граница между компонентами должна быть видна
из структуры каталогов, а не только из договорённостей.

Отдельно: файлы этапа 0 были загружены через веб-интерфейс GitHub и оказались
во вложенном каталоге `web-deception-stage0/web-deception/`, при этом `CLAUDE.md`
и `threat-model.md` существовали в двух идентичных копиях. Расходящиеся копии
правил безопасности — реальный риск: правится одна, читается другая.

## Решение
Каждый компонент — каталог верхнего уровня, документация и инфраструктура
вынесены отдельно:

```
sensor/          модуль Go (go.mod здесь, не в корне)
controlplane/    пакет Python
schemas/         JSON Schema — общий контракт между ними
deploy/          docker/ и compose/
test/            интеграционные и e2e тесты
tools/semgrep/   собственные правила статического анализа
scripts/         вспомогательные скрипты для Makefile и хуков
docs/            модель угроз, ADR, глоссарий
```

Дополнительно:

- Unit-тесты лежат рядом с кодом, который проверяют; в `test/` — только то,
  чему нужен поднятый стек целиком.
- Внутренние пакеты сенсора — в `sensor/internal/`. Это не соглашение,
  а правило компилятора Go: пакет внутри `internal/` невозможно импортировать
  из другого модуля. Граница проводится заранее, до того как появится соблазн
  её нарушить.
- Путь модуля Go — `github.com/azuresong-afk/web_deception/sensor`.
- Вложенный каталог выпрямлен, дубли удалены. `CLAUDE.md` существует
  в единственном экземпляре в корне, модель угроз — только в `docs/`.

## Альтернативы
- **Go-модуль в корне** (`cmd/`, `internal/`, `go.mod` на верхнем уровне),
  Python в подкаталоге. Так выглядит типичный Go-проект. Отвергнуто: делает Go
  «главным» языком репозитория, хотя control plane не менее важен; засоряет
  корень служебными файлами Go и усложняет фильтры путей в CI.
- **Раскладка по типу артефакта** (`src/`, `tests/`, `configs/`). Отвергнуто:
  при двух языках одно логическое изменение размазывается по всему дереву,
  и ревью такого PR требует прыжков между каталогами.
- **Отдельные репозитории** — отвергнуто в [ADR-0008](0008-monorepo.md).

## Последствия
- CI фильтрует запуски по путям: правка в `docs/` не запускает сборку Go,
  изменение в `sensor/` не гоняет тесты Python. Монорепозиторий остаётся
  быстрым, как и требует ADR-0008.
- Изменение общего контракта в `schemas/` видно в том же PR, что и правки
  в обоих компонентах — контракт не может разойтись незаметно.
- Цена: на верхнем уровне больше каталогов, чем в однокомпонентном проекте.
  Компенсируется коротким `README.md` в каждом каталоге.
