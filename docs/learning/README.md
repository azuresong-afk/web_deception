# Учебные материалы

Здесь — объяснения того, как и почему устроен продукт, записанные для
изучения, а не только для справки. Всё, что ассистент объясняет в чате
по ходу шага, попадает сюда, чтобы к этому можно было вернуться.

Чем это отличается от других документов:

| Документ | Что это | Обновляется |
|---|---|---|
| [guide.md](../guide.md) | инструкция: какие есть модули, как запустить, где что лежит | в каждом PR, всегда совпадает с кодом |
| [adr/](../adr/) | решения: что выбрали и почему | новое решение — новый ADR |
| **learning/** (здесь) | разборы: как это работает внутри, построчно там, где входные данные | пишется один раз на шаг, это снимок на момент шага |

Если разбор и код разошлись — прав код, а описание текущего состояния
смотрите в `guide.md`. Разбор показывает, как рассуждали, когда писали.

## Порядок изучения

1. [guide.md](../guide.md): разделы «Продукт в одном абзаце» и «Карта
   компонентов» — общая картина.
2. [threat-model.md](../threat-model.md) — от чего защищаемся. Все разборы
   ссылаются на угрозы по номерам T1…T16.
3. [go-reading.md](go-reading.md) — как читать Go-код продукта, и чек-лист
   ревью. Прочитать до первого разбора с кодом.
4. Разборы шагов — по порядку, из таблицы ниже.
5. [glossary.md](../glossary.md) — по мере встречи незнакомых терминов.

## Как устроен каждый разбор

По [шаблону](TEMPLATE.md): что и зачем → нужные понятия → как работает →
построчный разбор кода с входными данными → граница доверия → что может
пойти не так → как это проверено тестами → как проверить руками →
вопросы для самопроверки.

У вопросов ответы спрятаны в раскрывающиеся блоки. Сначала ответьте сами,
потом откройте: так материал запоминается, а не просто прочитывается.
